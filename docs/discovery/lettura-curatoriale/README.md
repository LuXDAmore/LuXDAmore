# LUXDAMORE / Visual Universe

1. Estrai l'intero ZIP in una cartella.
2. Apri [LETTURA-CURATORIALE.md](LETTURA-CURATORIALE.md) con un lettore Markdown (ad esempio Obsidian, Typora o VS Code con anteprima Markdown).
3. Consulta [INDICE-FOTOGRAFIE.md](INDICE-FOTOGRAFIE.md) per accedere alle 144 anteprime.

Mantieni la cartella `assets` accanto ai due documenti per visualizzare tutte le immagini offline. I riferimenti a siti esterni richiedono connessione. Le nove tavole sono costruite esclusivamente da fotografie fornite dall'autore. Non sono inclusi RAW o copie a piena risoluzione.
